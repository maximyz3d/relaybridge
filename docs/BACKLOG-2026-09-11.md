## New operational surfaces

- `GET /api/runs/active` exposes bounded descendant activity, CPU coverage,
  sampled warnings and finite native transport time remaining. Optional
  `childProcessPolicy` accepts `maxChildren`, `maxConcurrentTests` and `action`
  (`warn` by default or `stop`). Sampling cannot prevent a command starting.
- `POST /api/runs/:runId/cancel` requires the exact current request, invocation
  and attempt IDs. MCP exposes `cancel_active_run`. The response acknowledges
  stop intent and explicitly does not assert process-tree death.
- `POST /api/providers/perplexity/probe-answer` requires `confirmQuotaUse:true`
  and the exact expected account. MCP exposes `probe_provider_answer`. It uses
  one fixed prompt through ordinary admission and never retries or falls back.
  Passive readiness remains non-generating. A five-minute observation is scoped
  to account/config generation and does not prove current authentication/quota.
- Delivery receipts link request, invocation, attempt, task and result hash.
  Startup repairs missing receipt metadata from durable results without running
  tasks. Exact result acknowledgement is idempotent. Cached-token amplification
  is advice to review efficiency, never an automatic turn cap or quota estimate.

## Candidate and recovery authority

Candidate staging copies actual working bytes, including dirty and untracked
files, and rejects unsupported links/special files and incomplete scans. It
uses pinned directories, full final delta validation and durable evidence.
Any forbidden create/modify/delete/restore quarantines the entire candidate;
allowed changes are not salvaged from a mixed violation. It never applies edits
to the source. `atomicSnapshot:false` is intentional: concurrent host writers
require a separate ownership boundary, and metadata checks are not a multi-file
atomic snapshot. Provider code must not receive access to evidence or another
run's staging directories.

Neither elapsed time, a disappeared PID, a caller boolean, a successful model
answer nor a descendant census can release an expired writer lease. Historical
unbound reservations cannot be upgraded into trusted process ownership after
the fact. The shared running bridge and its other projects remain untouched.
